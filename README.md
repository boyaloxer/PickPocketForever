# Pick Pocket Forever

World of Warcraft addon for the **Forever** client (Interface 16001). Built for the BRD pickpocket farm and similar rogue loops.

- **Destroy** junkboxes as they land in your bags (one per key press or click, as required by the game API).
- **Sell** grey, white, and green pickpocket loot when you open a vendor; the sell list learns from Pick Pocket.
- **Minimap button** (Pick Pocket icon) opens a simple options window.
- **Slash:** `/ppf` (aliases: `/pickpocketforever`, `/junkbox`).

## Install

Unzip so the folder is:

`Interface\AddOns\PickPocketForever\`

## Options

From the minimap button or `/ppf`:

- Destroy junkboxes automatically  
- Sell pickpocketed items automatically  
- Show output in chat window  

Other settings: `/ppf help`
